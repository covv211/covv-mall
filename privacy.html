PRIVACY

개인정보 처리방침

코브 몰은 이름·연락처·주소를 받지 않아요. 다만 방문자 수를 세고 서버를 지키려고 접속 IP 주소를 기록해요. 무엇을, 왜, 얼마나 보관하는지 아래에 적었어요.

시행일: 2026년 10월 1일

1. 처리 목적

  • 오늘·전체 방문자 수를 세요. 같은 날 같은 IP는 한 번만 세요.
  • 서버를 공격하거나 해를 끼친 접속을 찾아 차단해요.

2. 처리하는 항목

  • 방문 기록: 접속 IP 주소, 그날 처음 접속한 시각 (페이지를 열 때 자동으로 기록)
  • 서버 접속 기록: 서버에 직접 들어온 요청의 IP 주소, 시각, 요청한 주소, 브라우저 정보 (오류가 나면 오류 기록에도 IP가 남아요)
  • 가방·닉네임·다이어리 같은 놀이 기록은 방문자 브라우저 안에만 저장되고 서버로 보내지 않아요. 쿠키는 쓰지 않아요.

3. 처리 근거

동의 없이 처리하며, 근거는 개인정보 보호법 제15조 제1항 제6호(서버 보안과 방문자 통계라는 운영자의 정당한 이익)예요. 목적에 필요한 최소한만 처리해요.

4. 보유 기간과 파기

  • 날짜별 방문 기록과 서버 접속 기록은 90일 보관한 뒤 자동으로 영구 삭제해요.
  • 서버에 해를 끼쳐 차단한 IP는 차단을 푸는 날까지 방화벽 차단 목록에 남아요.
  • 개인을 알아볼 수 없는 숫자(오늘·전체 방문자 수)만 계속 보관해요.

5. 제3자 제공과 처리 위탁

  • 방문 기록을 다른 곳에 주지 않아요.
  • 기록은 코브 몰 서버(카페24 가상서버, 국내 데이터센터)에 저장돼요.
  • 화면 파일은 GitHub Pages(GitHub, Inc.)에서, 글꼴·3D 프로그램은 Google Fonts·jsDelivr·cdnjs에서 내려받아요. 이 회사들도 각자의 방침에 따라 접속 IP를 처리할 수 있어요.

6. 기록을 원하지 않을 때

브라우저의 GPC(Global Privacy Control, 추적 거부) 설정을 켜면 IP를 기록하지 않아요. 이미 남은 기록은 아래 문의처로 삭제를 요청할 수 있어요.

7. 안전하게 지키는 방법

  • 방문 기록은 들어오는 즉시 한 줄씩 암호화(AES-256)해서 저장해요. 서버에는 잠그는 열쇠만 있고, 여는 열쇠는 인터넷에 연결되지 않은 곳에 봉인해 두어요. 그래서 운영자도 평소에는 기록을 볼 수 없고, 서버 공격 조사·수사기관 요청·방문자의 열람·삭제 요청이 있을 때만 열어요.
  • 하루가 지난 서버 접속 기록도 같은 방식으로 잠가요.
  • 서버는 암호 키로만 접속할 수 있고, 방화벽으로 필요한 문만 열어 두어요. 기록을 남기는 프로그램은 전용 계정으로 갇혀 있어 인터넷으로 나갈 수 없고, 기록 폴더를 누가 열어 보면 감사 기록이 남아요.

8. 방문자의 권리

내 IP 기록을 열람하거나 삭제·처리정지를 요청할 수 있어요. 확인을 위해 접속한 날짜와 IP 주소를 알려 주세요.

9. 개인정보 보호책임자와 문의

보호책임자: 코브 몰 운영자 코브
문의: GitHub 저장소 게시판 (누구나 볼 수 있는 곳이니 IP 주소는 적지 말고 '기록 요청'이라고만 남겨 주세요. 따로 연락드릴게요.)
